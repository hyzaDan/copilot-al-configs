# copilot-al-configs

AL development configuration for GitHub Copilot CLI and VS Code Insiders.

This repository keeps its runtime assets at the repository root.

For Git-based plugin installation, Copilot currently looks for a manifest at `.claude-plugin/plugin.json` or `.claude-plugin/marketplace.json`, not only at the repository root. This repository includes `.claude-plugin/plugin.json` for that compatibility while keeping the root layout unchanged.

Git install targets:
- Repository root: `hyzaDan/copilot-al-configs`
- Full URL: `https://github.com/hyzaDan/copilot-al-configs`
