Use [AL debugging](../../skills/al-debugging-methodology/SKILL.md) and its runtime-artifact reference. Stay read-only; analyze available exports and matching source. If the artifact needs an unavailable parser/viewer, request a supported export instead of claiming to have decoded it.

Return likely object/procedure scope, decisive evidence, confidence limits, and the next useful check. Keep raw traces out of the result and separate functional defects from performance hotspots.
